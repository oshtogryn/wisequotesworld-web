## Prompt quality rule — mandatory
A video prompt is NOT a short scene description. Every language prompt must be a production-ready Gemini/Veo instruction and include, where applicable:
- exact duration: 8 seconds unless explicitly changed;
- vertical 9:16 and publication-ready master intent;
- immediate first-frame visual hook; never black intro or empty pause;
- complete scene description and environment;
- subject/character description and action;
- camera framing, lens/shot feel and camera movement;
- explicit timeline/beat progression across the 8 seconds;
- lighting, palette, atmosphere and premium Wise Quotes visual treatment;
- motion/background motion so the result is not a static image;
- exact localized quote wording;
- explicit text timing: first quote block disappears before second appears; blocks never overlap;
- typography placement in upper-middle safe area and mobile readability;
- author only if `author_name` exists AND attribution is verified;
- native-language calm reflective voiceover, with exact wording and no added narration;
- soft music/ambience below voice;
- explicit forbidden output: instruction labels, automatic captions, unrelated text, third-party logos/watermarks, fake documentary claims;
- clean final frame and no unnecessary outro.

Prompts must be detailed enough to paste directly into Gemini without the user having to interpret or complete production instructions.

## Pinterest prompt rule during AI freeze
Prepare 8 detailed 2:3 still-image prompts per content item, preserving the SAME semantic story as each language video. The user generates the images manually. Prompts must specify composition, subjects, environment, camera/photographic treatment, lighting, palette, negative space/safe areas, exact quote/author/branding requirements where the chosen generator can reliably render them, and forbidden unrelated text/watermarks. Final image is uploaded through Admin and requires QA.

## Tomorrow-ready definition
A content item is ready for scheduling only when:
- source/attribution gate passes;
- all 8 localized quotes exist;
- 8 detailed video prompts exist;
- 8 Pinterest prompts exist;
- required platform copy exists;
- website page data exists;
- user-uploaded media is linked for active social languages;
- approval is explicit;
- Metricool scheduling package can be produced without consulting Google Sheets.
